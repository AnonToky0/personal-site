# 网页狐狸 · 形象探索

状态：用户已确认 A 的三种姿态和圆形图标，并要求继续实现互动。暖纸色保留；静态青凤蝶和第一版交互已接入。

## 当前互动

- 默认趴卧；鼠标在页面上时，每隔随机 18–38 秒短暂抬头约 2.8 秒。头部不追踪鼠标方向。
- 鼠标靠近狐狸约 72 px 内时坐起，青凤蝶替代指针。离开采用较宽阈值，避免边界反复切换。
- 停手后，青凤蝶留在指针位置，不再自动飞到狐狸上方。
- 移远或指针离开页面后，蝴蝶立即消失、恢复普通光标，狐狸恢复趴卧。上方停驻功能按用户 2026-09-26 的要求暂时移除。
- 90 秒没有鼠标、键盘或滚动输入后打盹；再次操作时醒来。
- 点击狐狸收起成 48 px 圆标，再点击展开；真实点击的收起选择保存在本机，换页/刷新保留。校样页手动选择姿态不会修改这一记忆。
- 支持键盘 Enter / 空格收起展开。触屏保留点击交互，不隐藏触屏设备光标；减少动态效果偏好会关闭过渡和自动随机抬头。
- 页面隐藏或失焦时停止定时器并恢复普通光标；组件移除时释放事件和计时器。

姿态切换采用约 240 ms 的透明度交叉淡化与极小位移，尚未制作连续动作帧或身体骨骼动画。蝴蝶的翅膀保持静态，只改变整体位置。

青凤蝶素材：[bluebottle-v1.png](../../src/assets/fox/bluebottle-v1.png)，使用内置 image_gen 生成；[完整提示词](bluebottle-v1.prompt.txt)。物种参考：[NParks 的 Common Bluebottle 资料](https://www.nparks.gov.sg/florafaunaweb/fauna/9/3/934)。以 Graphium sarpedon 的深色翅面与青绿带状斑纹为基础，按狐狸的绘本笔触重绘。

行为时间参数集中在 src/scripts/fox-behavior.ts；浏览器事件和清理逻辑在 src/scripts/fox-companion.ts。互动组件全站复用，/fox-preview 增加“自动陪伴”，也可手动切姿态、尺寸与背景。

验证：npm test 覆盖闲置/唤醒、随机抬头、靠近/停手保持指针位置/离开、收起优先级、失焦恢复、减少动态效果和预览隔离；浏览器检查姿态切换、指针恢复、跨页记忆、键盘操作与布局。npm run build 通过。未部署。
