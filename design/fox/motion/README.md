# 三种姿态 · 连续动作初稿

2026-10-16。预览入口：`/fox-preview#motion-preview`。

本轮制作可交互的动作样片，包含坐起、趴下、入睡、醒来；完整顺序约 11.3 秒，含姿态间的停留。每段 8 个播放帧位，4 段共 32 个帧位，连接处复用同一张静止姿态。起身与趴下、入睡与苏醒分别绘制，不使用简单倒放。

素材使用内置 `image_gen`，以现有三张获确认的狐狸原画为参考生成。它保留绘本风格，但不是对原画逐像素绑定的骨骼动画；转头和毛发轮廓仍有帧间变化。这是供确认动作方向与节奏的初稿。

播放器支持完整/单段播放、暂停、重播、0.5× / 1× / 1.5×、可选循环、时间轴、前后逐帧、点击分镜、三种背景和同步的 180 px 小尺寸预览。初次进入可见区域自动播放一次；系统减少动态效果时不自动播放，仍可由用户主动播放。滚出预览区或页面隐藏时暂停，组件移除时清理监听器与动画帧。

新动作在预览区独立展示；原网站的互动狐狸仍使用已确认的版本。预览区可见时隐藏原右下角狐狸，防止遮住播放器；向下滚动到原交互区后恢复显示。

验证：20 项测试通过；生产构建通过（26 页）；浏览器检查整段结束、半速入睡、逐帧切换、单段坐起、深色背景与 390 px 窄屏，无控制台错误。未提交或部署。
